# Chùa An Nhiên — GitHub Pages

Game web 3D chạy tĩnh, không cần backend. Three.js được tải từ CDN nên cần Internet.

## Chạy thử trên Windows
Double-click `run-local.bat` (cần Python 3), sau đó mở http://localhost:8000.

## Deploy GitHub Pages
Đưa toàn bộ nội dung thư mục này lên nhánh `main`, sau đó vào Settings → Pages → Deploy from a branch → `main` → `/(root)`.

## Điều khiển
- WASD / phím mũi tên: di chuyển.
- Kéo chuột: xoay camera; cuộn chuột: zoom.
- Các nút hoạt động: lễ Phật, thiền, lần tràng hạt, dâng hương, thỉnh chuông.

## Phiên bản 2
Nội thất có sàn gỗ dạng ván, tranh nền brocade tạo bằng CanvasTexture, tượng Phật vàng dựng từ hình khối 3D chi tiết hơn, vòng hào quang, hoa sen và ánh sáng ấm.
